═══════════════════════════════════════════════════════════════

⚡ FASTEST FIX (Do These First - 15 Minutes)

STEP 1: Verify Environment Variable (2 min)
────────────────────────────────────────────
cd frontend
cat .env.local

Expected: NEXT_PUBLIC_API_URL="http://localhost:3001/api/v1"

If missing or wrong:
echo 'NEXT_PUBLIC_API_URL="http://localhost:3001/api/v1"' > .env.local

Then restart:
Remove-Item -Recurse -Force .next
npm run dev


STEP 2: Regenerate Prisma Client (3 min)
────────────────────────────────────────────
cd backend
Remove-Item -Recurse -Force node_modules\.prisma
Remove-Item -Recurse -Force node_modules\@prisma
npx prisma generate
npm run start:dev

Wait for: "🚀 Server running on http://localhost:3001/api/v1"


STEP 3: Test Backend API Directly (2 min)
────────────────────────────────────────────
Open browser:
http://localhost:3001/api/v1/attendance/all-students?date=2026-05-10

Expected: JSON with students array
If 401: Token issue
If 500: Backend crash (check terminal)
If timeout: Database issue


STEP 4: Check Browser Console (3 min)
────────────────────────────────────────────
Open attendance page
Press F12 → Console tab

Look for:
✅ "API Base URL: http://localhost:3001/api/v1"
✅ "🚀 API Request: GET /attendance/all-students..."
✅ "🔐 Token attached"
✅ "✅ API Response: {...}"

If missing any:
❌ No base URL → Environment variable not loaded
❌ No token → Login again
❌ No response → Check Network tab


STEP 5: Check Network Tab (3 min)
────────────────────────────────────────────
F12 → Network tab → Reload page

Find: all-students request

Check:
- Status: Should be 200 (not 401, 500, or pending)
- Request URL: Should be http://localhost:3001/api/v1/attendance/all-students?date=...
- Request Headers: Should have "Authorization: Bearer ..."
- Response: Should have data array

If wrong URL:
→ Environment variable issue (Step 1)

If 401:
→ Token issue (login again)

If 500:
→ Backend crash (check backend terminal)

If pending forever:
→ Backend not responding (restart backend)


STEP 6: Check Backend Terminal (2 min)
────────────────────────────────────────────
Look for:
✅ "📅 Fetching attendance for date: 2026-05-10"
✅ "✅ Found X active students"
✅ "✅ Returning X students with attendance"

If errors:
❌ "Invalid date" → Date format issue
❌ "PrismaClientValidationError" → Regenerate Prisma (Step 2)
❌ "Cannot find module" → npm install
❌ "Database connection" → Check PostgreSQL
