## 🚀 سسٹم شروع کرنے کا طریقہ

### طریقہ 1: PowerShell Script استعمال کریں (آسان)

1. VS Code میں Terminal کھولیں (Ctrl+Shift+`)
2. یہ کمانڈ چلائیں:

```powershell
cd Mess_Management_System
.\restart-backend.ps1
```

3. نیا Terminal کھولیں اور Frontend شروع کریں:

```bash
cd frontend
npm run dev
```

### طریقہ 2: Manual Commands (اگر script کام نہ کرے)

**Backend شروع کرنا:**

```bash
cd Mess_Management_System/backend

# پرانی files صاف کریں
rm -rf dist
rm -rf node_modules/.prisma
rm -rf src/generated

# Prisma Client دوبارہ بنائیں
npm run prisma:generate

# Backend شروع کریں
npm run start:dev
```

**Frontend شروع کرنا (نیا Terminal):**

```bash
cd Mess_Management_System/frontend
npm run dev
```

## 📋 حاضری کا نیا سسٹم

### کیسے کام کرتا ہے؟

1. **خودکار حاضر:**
   - تمام طلباء خودکار طور پر **حاضر** ہیں
   - Admin کو صرف غیر حاضر یا رخصت والوں کو مارک کرنا ہے

2. **چارج کا نظام:**
   - ✅ **حاضر** = چارج لگے گا
   - ✅ **غیر حاضر** = چارج لگے گا
   - ❌ **رخصت** = کوئی چارج نہیں

3. **استعمال کا طریقہ:**
   - تاریخ منتخب کریں
   - روزانہ چارج لکھیں (مثلاً 100 روپے)
   - جو طالب علم غیر حاضر ہو، اس پر "غیر حاضر" کلک کریں
   - جو رخصت پر ہو، اس پر "رخصت" کلک کریں
   - "محفوظ کریں" بٹن دبائیں

## ❌ مسائل اور حل

### مسئلہ: Backend میں "Property 'meal' does not exist" error

**حل:**
```bash
cd backend
rm -rf node_modules/.prisma
rm -rf src/generated
npm run prisma:generate
npm run start:dev
```

### مسئلہ: Frontend میں "ڈیٹا لوڈ نہیں ہو سکا"

**حل:**
1. Backend چل رہا ہے؟ (Terminal چیک کریں)
2. Browser console کھولیں (F12 دبائیں)
3. Errors دیکھیں
4. Backend restart کریں

### مسئلہ: ممبرز میں طلباء ہیں لیکن حاضری میں نہیں

**حل:**
1. یہ مسئلہ PrismaModule کی وجہ سے تھا - اب ٹھیک ہے ✅
2. Backend کو صاف کر کے دوبارہ شروع کریں
3. Browser cache صاف کریں (Ctrl+Shift+Delete)
4. Page refresh کریں (Ctrl+F5)

### مسئلہ: "EPERM: operation not permitted"

**حل:**
1. VS Code بند کریں
2. Task Manager کھولیں (Ctrl+Shift+Esc)
3. تمام "node.exe" processes بند کریں
4. VS Code دوبارہ کھولیں
