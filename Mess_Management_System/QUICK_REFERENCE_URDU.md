## 📱 مرکزی خصوصیات

### 1️⃣ ڈیش بورڈ
```
📊 کل طلباء
💰 کل بیلنس
✅ آج کی حاضری
💸 اخراجات
```

### 2️⃣ ممبرز (طلباء)
```
➕ نیا طالب علم شامل کریں
   ├─ نام
   ├─ فون نمبر
   ├─ کمرہ نمبر
   ├─ ہال / ہاسٹل ⭐
   └─ ابتدائی بیلنس

👁️ تمام طلباء دیکھیں
🔍 نام سے تلاش کریں
✏️ معلومات تبدیل کریں
🗑️ طالب علم کو محفوظ کریں (Archive)
```

### 3️⃣ حاضری
```
📅 تاریخ منتخب کریں
👥 تمام طلباء کی فہرست

ہر طالب علم کے لیے:
├─ نام
├─ ہال ⭐
├─ کمرہ
├─ بیلنس
└─ حاضری کے بٹن:
    ├─ حاضر (چارج ہوگا)
    ├─ غیر حاضر (چارج ہوگا)
    └─ رخصت (چارج نہیں)

💾 تمام محفوظ کریں
```

### 4️⃣ ادائیگیاں
```
➕ نئی ادائیگی
   ├─ طالب علم منتخب کریں
   ├─ رقم داخل کریں
   └─ طریقہ منتخب کریں:
       ├─ نقد
       ├─ ایزی پیسہ
       ├─ جاز کیش
       └─ بینک ٹرانسفر

نتیجہ:
✅ بیلنس فوری بڑھ جائے گا
✅ لین دین محفوظ ہوگا
✅ ہر جگہ update ہوگا
```

### 5️⃣ اخراجات
```
➕ نیا اخراجہ
   ├─ عنوان
   ├─ رقم
   ├─ قسم:
   │   ├─ سبزیاں
   │   ├─ گوشت
   │   ├─ چاول
   │   ├─ آٹا
   │   ├─ گیس
   │   ├─ تنخواہ
   │   ├─ گروسری
   │   └─ دیگر
   └─ تاریخ

📊 خلاصہ دیکھیں
🗑️ اخراجہ مٹائیں
```

### 6️⃣ رپورٹس
```
📄 لیجر رپورٹ
   └─ ہر طالب علم کا مکمل حساب

📊 حاضری رپورٹ
   └─ تاریخ کے حساب سے حاضری

💸 اخراجات رپورٹ
```

## 💰 بیلنس کا حساب

### فارمولا:
```
موجودہ بیلنس = ابتدائی بیلنس + کل جمع - کل چارجز
```

### مثال:
```
ابتدائی بیلنس:        10,000 روپے
+ جنوری میں جمع:       5,000 روپے
+ فروری میں جمع:       5,000 روپے
- 30 دن کے چارجز:     -6,000 روپے (200/دن)
- 28 دن کے چارجز:     -5,600 روپے (200/دن)
────────────────────────────────
موجودہ بیلنس:          8,400 روپے
```

### اہم نکتہ:
```
✅ بیلنس صرف ایک جگہ محفوظ ہے: student.balance
✅ تمام صفحات اسی بیلنس کو دکھاتے ہیں
✅ کوئی تضاد نہیں
```

## 🛠️ مسائل کا حل

### اگر frontend نہ کھلے:
```powershell
cd frontend
Remove-Item -Recurse -Force .next
npm run dev
```

### اگر backend کام نہ کرے:
```powershell
cd backend
npm run start:dev
```

### اگر database میں مسئلہ ہو:
```powershell
cd backend
npx prisma migrate deploy
npx prisma generate
npm run start:dev
```

### سب کچھ صاف کرنے کے لیے:
```powershell
# Backend
cd backend
Remove-Item -Recurse -Force dist
Remove-Item -Recurse -Force node_modules/.prisma
npx prisma generate
npm run start:dev

# Frontend
cd frontend
Remove-Item -Recurse -Force .next
npm run dev
```
